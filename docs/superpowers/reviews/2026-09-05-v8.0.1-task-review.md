## Task 4：中文设置安全边界

复核时发现原实现会把普通 `.codex/.env` / `config.toml` 的 `language` / `locale` / `ui_language` 当作 Desktop UI 配置，存在“文件写成功但界面没变”的假成功风险。

已执行 RED → GREEN 修复：

- RED：未经白名单的 `.codex/config.toml language=en-US` 必须拒绝自动写入。
- GREEN：`CodexLanguageService` 增加显式可信 UI 配置路径白名单。
- 正向测试：只有明确批准的测试适配器可写 `zh-CN` 并恢复原值。
- 负向测试：未批准文本配置、未知数据库/资源均不得修改。
- 当前没有已验证本地 UI 适配器时，显示“需要用户操作”，引导应用内“设置 → 通用 → 语言”。

结论：通过。
