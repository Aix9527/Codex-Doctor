## 语言切换安全审查

- `中文` 目标固定为 `zh-CN`，`English` 目标固定为 `en-US`。
- 可信本地语言适配器只接受显式批准的配置路径；普通 `.codex/.env`、`config.toml` 的 `language/locale/ui_language` 不会自动被当成 Desktop UI 设置。
- 无可信本地适配器时，仅尝试 Windows UI Automation。
- UI Automation 只绑定 discovery 扫描确认的 Desktop EXE 与 PID，并再次比较真实进程路径。
- 找不到 Settings / General / Language / 目标语言控件时返回失败。
- 目标语言选择后必须再次验证；无法确认目标语言时 `Success=false / Verified=false`。
- 不修改未知数据库、MSIX/AppX、安装资源或 Desktop 二进制文件。

## 安装管理安全审查

- Desktop 自动安装/卸载只使用 Microsoft Store / winget 官方包 ID `9NT1R1C2HH7J`。
- CLI 自动安装/卸载只使用 npm 包 `@openai/codex`。
- winget/npm 缺失时返回 `ManualRequired`，不下载第三方安装器、不猜测 URL。
- 安装/卸载命令退出码为 0 不能单独构成成功；动作后必须重新 discovery 扫描确认目标状态。
- CLI 安装还会执行 `codex --version` 验证。
- 卸载 GUI 明确二次确认，并保留 `.codex`、用户项目、Codex Doctor 备份和诊断报告。
