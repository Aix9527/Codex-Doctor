# Codex Doctor V8.1.1 — 中英文一键切换与安装管理设计

日期：2026-09-06  
状态：DESIGN APPROVED  
目标分支：`feature/v8.1.1-language-install`

## 1. 目标

V8.1.1 修正 V8.1.0 的语言交互，并新增 Codex 安装管理入口。

主界面在完成扫描后固定提供：

```text
[ 启动 Codex ] [ 重启 Codex ]
[ 一键修复 ]
[ 智能迁移/恢复 ]
[ 中文 ] [ English ]
[ 安装 / 卸载 ]
[ 导出完整报告 ]
```

语言功能不再把“需要用户操作”作为主按钮。用户点击 `中文` 或 `English` 后，Codex Doctor 必须尝试自动切换并验证；失败时明确报告失败，禁止伪报成功。

安装管理必须区分 **ChatGPT/Codex Desktop** 与 **Codex CLI**，不能把二者混为一个安装对象。

## 2. 官方安装依据

- OpenAI 官方 Codex CLI 安装命令：`npm i -g @openai/codex`。
- OpenAI 官方 Windows ChatGPT 应用通过 Microsoft Store 分发；官方帮助页给出 Store package id `9NT1R1C2HH7J`，并给出 winget 安装方式。
- Codex 可通过 ChatGPT desktop app 的 Codex mode 使用；CLI 是独立客户端。

V8.1.1 不下载未知第三方安装器，不使用第三方镜像。

## 3. 中文 / English 双向一键切换

### 3.1 UI

扫描完成后同时显示两个按钮：

```text
当前语言：未知 / 中文 / English
[ 中文 ] [ English ]
```

若已确认目标语言，目标按钮可显示 `✓ 中文` 或 `✓ English`。

### 3.2 自动切换策略

按优先级执行：

1. 若存在经过明确白名单批准的本地 Desktop UI 语言适配器，使用该可逆适配器。
2. 否则使用 Windows UI Automation 操作 Desktop 自身的 `Settings → General → Language` 界面。
3. UI Automation 只允许操作已扫描确认的 Codex/ChatGPT Desktop 进程窗口，不允许向任意窗口发送全局输入。
4. 自动寻找中英文可访问性名称：`Settings/设置`、`General/通用`、`Language/语言`、`Chinese/中文/简体中文`、`English`。
5. 切换后必须通过可访问性状态或可信语言适配器重新读取确认。
6. 若应用要求重启，使用已扫描确认的真实 EXE/PID 重启，然后再次验证。
7. 无法确认时返回失败或不确定，不显示“切换成功”。

### 3.3 安全边界

禁止：

- 猜测或修改未知 SQLite/LevelDB 字段；
- 修改 MSIX/AppX 包；
- 修改签名资源或二进制文件；
- 使用屏幕坐标硬点击；
- 向未确认窗口发送键盘输入；
- 仅因为点击动作成功就宣告语言切换成功。

## 4. 安装 / 卸载 Codex

### 4.1 主入口

主界面新增：

```text
[ 安装 / 卸载 ]
```

点击打开 `CodexInstallManagerForm`，显示两个独立产品：

```text
ChatGPT / Codex Desktop
状态：已安装 / 未安装 / 未知
版本：...
[安装 Desktop] / [卸载 Desktop]

Codex CLI
状态：已安装 / 未安装 / 缺少 npm / 未知
版本：...
[安装 CLI] / [卸载 CLI]
```

### 4.2 Desktop 安装

优先使用：

```text
winget.exe install --id 9NT1R1C2HH7J --source msstore --accept-package-agreements --accept-source-agreements --silent
```

安装前检查 `winget.exe` 是否可用。不可用时返回 `ManualRequired`，并允许打开 Microsoft Store 官方应用页；不得从第三方下载 EXE/MSIX。

安装完成后必须重新扫描 Desktop 安装路径并确认发现客户端，才显示成功。

### 4.3 Desktop 卸载

使用 Windows/winget 的已安装包卸载能力，不直接删除 WindowsApps、LocalAppData 或程序目录。

卸载前必须弹出明确确认，并固定声明：

- 默认保留 `%USERPROFILE%\.codex`；
- 默认保留用户项目；
- 默认保留 Codex Doctor 备份和报告；
- 不执行“彻底清理用户数据”。

卸载完成后重新扫描，只有 Desktop 已不再被发现才显示成功。

### 4.4 CLI 安装

前提：`npm.cmd` 可执行。

安装命令：

```text
npm.cmd install -g @openai/codex
```

完成后重新执行 CLI discovery，并至少验证 `codex --version` 可成功运行。

若 npm 不存在，不自动安装 Node.js；标记 `ManualRequired` 并说明需先安装受信任的 Node/npm。

### 4.5 CLI 卸载

命令：

```text
npm.cmd uninstall -g @openai/codex
```

卸载完成后重新扫描；只有 CLI 不再被发现时才显示成功。

CLI 卸载不得删除 `%USERPROFILE%\.codex`。

## 5. 命令执行规则

- 不使用 `powershell.exe` / `pwsh.exe`。
- 允许调用经过白名单的 `winget.exe`、`npm.cmd`、`cmd.exe`、`codex`。
- 所有命令必须有超时、退出码、stdout/stderr 截断与中文错误说明。
- 命令参数固定生成，不接受未经验证的用户自由拼接参数。

## 6. 扫描与状态联动

安装/卸载或语言切换结束后必须触发新的 V8.1.1 全量扫描，不复用旧扫描快照。

安装管理器和主界面以最新扫描为唯一事实源。

## 7. 版本与发布

- 产品版本：`8.1.1`。
- Release：`v8.1.1`。
- 资产：`CodexDoctor.exe`、`CodexDoctor.exe.sha256`。
- 保持 `requireAdministrator`。
- 保持 win-x64 / self-contained / single-file。
- 保持无 PowerShell 运行依赖和无外置运行 DLL。
