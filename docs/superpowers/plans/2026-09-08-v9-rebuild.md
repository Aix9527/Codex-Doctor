目标：按用户最新要求重建功能执行链；一键修复重连必须发现本地代理并实际创建或更新用户 .codex/.env。

架构：新增独立 V9 入口、界面与核心服务，历史 V8 保留用于回归。语言自动化也已改为 V9 的强类型 .NET UI Automation 实现，不再引用 V8 程序集。主界面直接调用服务，不用反射附加按钮，不使用旧的“全量扫描正常”推断修复成功。

- [x] 复现旧版 .env 空格写法未被替换、旧代理阻止探测、误把 Doctor 识别成 Desktop。

- [x] 新建主界面与设备扫描：独立 Codex 身份、真实安装路径、用户数据目录、配置元信息、磁盘、代理；统一忙碌/取消状态。
- [x] 接通启动、重启、CLI 安装升级卸载、官方 Desktop 安装、用户 PATH 修复、报告与备份恢复；保留语言适配并如实报告未支持状态。
