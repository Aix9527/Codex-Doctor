# Codex Doctor V8.2.0 Reconnecting Self-Heal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Codex Doctor 增加针对 Desktop 持续 Reconnecting 的端到端自愈闭环，并把“网络恢复”和“Desktop 真正恢复”分开验证。

**Architecture:** 在现有 `CodexHealthScanner`、`DiagnosisService`、`RepairOrchestrator`、Desktop discovery/restart 基础上新增一个只组合既有白名单动作的 `ReconnectingSelfHealService`。服务先扫描、生成计划、执行动作、再扫描，并由独立分类器根据修复后网络路径与 Desktop 状态给出稳定终态；UI 只负责触发、进度和展示，不承载判定逻辑。

**Tech Stack:** C#、.NET 8、WinForms、现有 Codex Doctor native 测试框架、GitHub Actions Windows runner。

**Spec:** `docs/superpowers/specs/2026-09-07-v8.2-reconnecting-self-heal-design.md`

## Global Constraints

- 产品版本固定为 `8.2.0`，Release tag 固定为 `v8.2.0`。
- 只允许 `codex.proxy.env`、`git.proxy.clear`、`npm.proxy.clear`、`codex.desktop.restart` 进入 Reconnecting 自愈计划。
- 直连 TLS 可用时不得为了自愈写入代理。
- 只有实际通过代理 HTTPS 验证的 URL 才能写入 `.codex/.env`。
- `.codex/.env` 写前备份，验证失败必须回滚，并保留无关配置。
- 默认不得自动写 Windows 用户级 `HTTP_PROXY` / `HTTPS_PROXY`。
- Desktop 操作必须绑定 discovery 确认的 EXE/PID。
- 不新增运行时 PowerShell 依赖，不新增第三方安装器，不新增常驻后台服务。
- 发布继续为 `.NET 8 / win-x64 / self-contained / single-file`，manifest=`requireAdministrator`，资产固定为 `CodexDoctor.exe` 与 `CodexDoctor.exe.sha256`。
