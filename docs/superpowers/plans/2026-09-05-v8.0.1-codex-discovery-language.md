# Codex Doctor V8.0.1 本机发现与中文设置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Codex Doctor V8 Native 增加本机 Codex/ChatGPT Desktop 与 CLI 自动发现、配置审计、真实路径重启/doctor，以及安全可逆的一键简体中文能力。

**Architecture:** 新增独立 `CodexDiscoveryService` 负责只读发现，`CodexLanguageService` 负责语言能力检测与可逆设置，`CodexDiscoveryForm` 负责展示。`RepairService` 只接受发现层提供的显式路径执行动作，避免再次硬编码 `codex` 或 `chatgpt:`。

**Tech Stack:** C#、.NET 8、WinForms、System.Diagnostics、Microsoft.Win32、System.Text.Json、Windows GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-09-05-codex-local-discovery-design.md`

## Global Constraints

- 版本：V8.0.1。
- Windows 目标：`win-x64`。
- 发布：`self-contained` + `PublishSingleFile=true` + `IncludeNativeLibrariesForSelfExtract=true`。
- 原生运行时代码禁止依赖 `powershell.exe`、`pwsh.exe`、`.ps1`、`.psm1`。
- 扫描默认只读。
- 不读取/导出 token、API key、cookie、密码、认证会话内容。
- 不修改签名后的 MSIX/AppX 安装内容，不破解资源文件。
- 不存在稳定可逆语言配置时，只返回需要用户操作，不得伪报设置成功。
- 所有语言修改必须可恢复。
