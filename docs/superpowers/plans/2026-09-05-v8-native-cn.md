# Codex Doctor V8 Native 中文原生版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 V7.1.2 的核心能力迁移为真正的 C#/.NET 8 Windows 原生单文件 EXE，并将所有用户可见界面、弹窗、日志和诊断建议统一为中文。

**Architecture:** 保留 V7 PowerShell 版作为历史兼容实现；新增 `versions/v8-native`，采用 WinForms + 独立诊断/修复/迁移服务。发布目标为 `win-x64`、`self-contained=true`、`PublishSingleFile=true`，运行时不调用 PowerShell，也不依赖 `.ps1/.psm1`。

**Tech Stack:** C# 12、.NET 8、WinForms、System.Net、System.Diagnostics、System.Text.Json、GitHub Actions Windows runner。

**Spec:** 本计划同时吸收 V7 既有安全约束和 2026-09-05 实机诊断样本：DNS 正常、直连 TLS 超时、`http://127.0.0.1:7897` 代理 HTTPS 可用、`.codex/.env` 缺失时，必须判定为“需要配置代理”，不得误报为 TLS 故障。

## Global Constraints

- 诊断默认只读；修复前必须明确确认。
- 默认只修改 `%USERPROFILE%\.codex\.env`；Windows 用户环境变量必须显式勾选。
- DNS/TLS/TUN 仅诊断，不自动修改系统网络或安全设置。
- 代理只有通过真实 HTTPS 验证后才能作为修复候选。
- V8 原生运行链不得启动 `powershell.exe`、`pwsh.exe`，也不得加载 `.ps1/.psm1`。
- 所有用户可见文本使用简体中文。
