# Codex Doctor V8.1.1 Implementation Plan

**Goal:** 在 V8.1.0 维修中心上增加中文/English 真正双向一键切换，以及 Desktop/CLI 一键安装卸载，并保持所有 V8.1 安全与发布门禁。

**Spec:** `docs/superpowers/specs/2026-09-06-v8.1.1-language-install-design.md`

## Task 0 — CI 分支门
- 修改 `.github/workflows/v8-native.yml`，让 `feature/v8.1.1-language-install` 触发 Windows 原生 CI。

## Task 1 — V8.1.1 UI/版本 RED→GREEN
- 新增 `TaskV811UiContract.cs`。
- RED：要求 `Version=8.1.1`，主界面源码同时包含 `中文`、`English`、`安装 / 卸载`。
- GREEN：最小更新版本和主界面控件骨架，不接生产行为。

## Task 2 — 双向语言切换 RED→GREEN
- 新增 `DesktopLanguageSwitchService.cs`。
- 新增 `IUiLanguageAutomationBackend`，生产实现 `WindowsUiAutomationLanguageBackend`。
- 测试：可信 adapter 优先；无 adapter 时调用 UI Automation；绑定已确认 Desktop；目标 zh-CN/en-US；未验证不得成功；需要重启时使用真实 EXE/PID 后再验证。
- 主界面将旧单按钮 `一键中文` 替换为两个固定按钮 `中文` / `English`。

## Task 3 — 安装管理后端 RED→GREEN
- 新增 `CodexInstallManager.cs` 与命令执行抽象。
- Desktop install 固定 package id `9NT1R1C2HH7J`，使用 `winget.exe`。
- Desktop uninstall 使用 `winget uninstall`，不得删目录/`.codex`。
- CLI install：`npm.cmd install -g @openai/codex`。
- CLI uninstall：`npm.cmd uninstall -g @openai/codex`。
- winget/npm 缺失 => ManualRequired。
- 每次动作后调用 discovery 验证，不以退出码单独判定成功。

## Task 4 — 安装管理 GUI RED→GREEN
- 新增 `CodexInstallManagerForm.cs`。
- 主界面新增 `安装 / 卸载`。
- 显示 Desktop/CLI 独立状态和版本。
- 卸载有二次确认并明确默认保留 `.codex`、项目、备份、报告。
- 成功后关闭/刷新管理器并触发主界面全量扫描。

## Task 5 — 发布收官 RED→GREEN
- 更新 README / CHANGELOG / Release Notes。
- 新增 `.github/workflows/release-v8.1.1.yml`。
- 新增 release contract：版本、tag、两个资产、管理员 manifest、单文件、无 PowerShell/外置 DLL、SHA256。
- 完整 Windows CI GREEN 后创建 PR；PR CI GREEN、Review 无 blocker 后再合并；合并后验证 `v8.1.1` Release 和资产 digest。
