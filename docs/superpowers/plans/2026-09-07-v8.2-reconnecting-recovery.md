# Codex Doctor V8.2.0 Reconnecting Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 V8.1.2 的网络诊断与安全修复能力升级为面向 Codex/ChatGPT Desktop 一直 Reconnecting 的端到端自愈闭环，只有网络与 Desktop 双验证通过才返回恢复成功。

**Architecture:** 新增 `ReconnectingRecoveryService` 作为纯编排层，消费既有 discovery、diagnosis、RepairPlan/repair engine 和真实 Desktop restart 能力，不复制底层代理探测逻辑。服务输出结构化 `ReconnectingRecoveryResult`，主界面新增专项自愈入口，报告导出器记录 before/after ScanId 与恢复状态；发布层升级到 8.2.0 并保留所有原生单文件安全门。

**Tech Stack:** C# 12, .NET 8, WinForms, Windows x64, GitHub Actions, 现有自定义 console contract tests

**Spec:** `docs/superpowers/specs/2026-09-07-v8.2-reconnecting-recovery-design.md`

## Global Constraints

- 产品版本固定为 `8.2.0`，Release tag 固定为 `v8.2.0`。
- 只使用既有已验证 diagnosis 事实选择代理，不允许根据常见端口猜测代理。
- 自动修复只执行 RepairPlan 白名单动作；`.codex/.env` 修改必须备份、验证、失败回滚。
- 直连健康时不得为了“统一配置”强制写代理。
- 最终 `RECOVERED` 必须同时满足网络验证与 Desktop 重新 discovery/运行验证。
- 不调用 `powershell.exe` / `pwsh.exe`，不新增第三方运行时依赖。
- 保持 Windows `requireAdministrator`、`win-x64`、self-contained、single-file、无外置运行 DLL。
