# Codex Doctor V8.1 Repair Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Codex Doctor 升级为必须管理员启动、先统一扫描、按严重度展示多个并存问题、对全部可安全自动修复问题执行事务式一键修复并自动复检的 V8.1 维修中心，同时加入作者信息与隐私安全的完整报告导出。

**Architecture:** 现有 `DiagnosisService`、`CodexDiscoveryService`、`MigrationService`、`CodexLanguageService` 保留为底层能力；新增 `CodexHealthScanner`、`CodexIssueClassifier`、`CodexRepairEngine`、`RepairActionCatalog`、`MainDashboardState` 和 `HealthReportExporter`。`MainForm` 只做状态展示和用户事件，不直接承担问题分类、修复编排或报告脱敏。

**Tech Stack:** C# / .NET 8 / WinForms / win-x64 self-contained single-file / GitHub Actions Windows runner

**Spec:** `docs/superpowers/specs/2026-09-06-v8.1-repair-center-design.md` + `docs/superpowers/specs/2026-09-06-v8.1-author-metadata-addendum.md`

## Global Constraints

- 正式版本固定为 `8.1.0`。
- 正式 EXE 必须使用 manifest `requestedExecutionLevel=requireAdministrator`；拒绝 UAC 时不进入主界面。
- 扫描默认只读；扫描阶段不改注册表、不改 PATH、不删除文件、不写配置。
- 问题严重度固定为 `Critical → Urgent → Warning → Info → Ok`。
- 一键修复只处理“可明确检测 + 有确定修复策略 + 可执行后验证”的问题。
- `ManualRequired` / `ExternalRequired` 永不伪报 Fixed。
- 默认一键修复不得写 Windows 用户级 HTTP/HTTPS 代理环境变量。
- 修复开始前允许取消；进入写事务后不提供强制中途取消。
- 需要备份的动作必须先备份；验证失败必须执行该项 Rollback。
- 一键修复结束后必须执行全量重新扫描。
- 中文设置只允许可信 Desktop UI 适配器自动写入，不修改 MSIX/AppX、未知数据库或二进制资源。
- 导出报告把用户主目录路径规范化为 `%USERPROFILE%`，Token/Key/Secret/Password/Cookie/Auth/Session 不得泄露。
- 主界面固定显示 `软件作者：Aix ｜ QQ：976936105 ｜ 抖音：xch03209527`。
- 健康报告只包含 `软件作者=Aix`，不把 QQ/抖音写入诊断数据。
- 运行时代码不得依赖 PowerShell；正式发布仍为真正单文件 `CodexDoctor.exe` + `CodexDoctor.exe.sha256`。
