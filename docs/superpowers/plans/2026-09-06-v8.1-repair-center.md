# Codex Doctor V8.1 Repair Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Codex Doctor 从多按钮工具集合升级为必须管理员启动、先统一扫描、按严重度展示问题、对全部可安全自动修复问题执行事务式一键修复并自动复检的 V8.1 维修中心，同时加入作者信息与完整报告导出。

**Architecture:** 保留现有 `DiagnosisService`、`CodexDiscoveryService`、`MigrationService`、`CodexLanguageService` 作为底层能力，在其上新增 `CodexHealthScanner`、`CodexIssueClassifier`、`CodexRepairEngine` 与 `MainDashboardState`。`MainForm` 只负责状态展示和用户事件；所有写操作通过 RepairPlan 白名单执行，必须具备验证，必要时具备备份与回滚。

**Tech Stack:** C# / .NET 8 / WinForms / win-x64 self-contained single-file / GitHub Actions Windows runner

**Spec:** `docs/superpowers/specs/2026-09-06-v8.1-repair-center-design.md` + `docs/superpowers/specs/2026-09-06-v8.1-author-metadata-addendum.md`

## Global Constraints

- 正式版本固定为 `8.1.0`。
- 正式 EXE 使用 manifest `requestedExecutionLevel=requireAdministrator`，用户拒绝 UAC 时不进入主界面。
- 扫描默认只读；扫描阶段不改注册表、不改 PATH、不删除文件、不写配置。
- 问题严重度固定：`Critical → Urgent → Warning → Info → Ok`。
- 一键修复只处理“可明确检测 + 有确定修复策略 + 可执行后验证”的问题；`ManualRequired` / `ExternalRequired` 永不伪报 Fixed。
- 默认一键修复不得写 Windows 用户级 HTTP/HTTPS 代理环境变量。
- 修复开始前允许取消；进入写事务后不提供强制中途取消。
- 需要备份的修复动作必须先备份；验证失败必须执行该项 Rollback。
- 一键修复结束后必须执行全量重新扫描。
- 中文设置继续只允许可信 UI 适配器自动写入，不修改 MSIX/AppX、未知数据库或二进制资源。
- 导出报告默认把用户主目录路径规范化为 `%USERPROFILE%`，Token/Key/Secret/Password/Cookie/Auth/Session 不得泄露。
- 主界面固定显示 `软件作者：Aix ｜ QQ：976936105 ｜ 抖音：xch03209527`。
- 健康报告只写 `软件作者=Aix`，不把 QQ/抖音写入诊断数据。
- 运行时代码不得依赖 PowerShell；正式发布仍为真正单文件 `CodexDoctor.exe` + `CodexDoctor.exe.sha256`。
