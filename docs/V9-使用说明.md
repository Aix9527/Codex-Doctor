# Codex Doctor V9 使用说明

## 一键修复重连

1. 启动本地 HTTP / mixed 代理。
2. 打开 Codex Doctor V9。
3. 确认 `.codex` 数据目录。
4. 点击「一键修复重连」。
5. 程序发现候选代理并进行 HTTPS 验证。
6. 验证通过后备份并更新 Codex 专用配置。
7. 失败自动回滚。

## 安全原则

- 不直接修改 Windows 全局代理。
- 未验证代理不会写入配置。
- 自动修复均保留备份。
- 不伪造 Reconnecting 已恢复状态。

## 验证

V9 发布前已完成行为测试、自包含 EXE 发布验证和 SHA256 校验。
